# Concerned Sprint

A small Demonologist infinite-sprint mod by The Concerned Cat.

Status: development kickoff; no playable or compatible build has been verified yet.

Scope: unlimited sprint duration for the locally controlled player, original movement speed and sprint controls, and an enable/disable setting. No additional gameplay features.

Development follows GitHub issues in `Weakened/ConcernedSprint`. Read [AGENTS.md](AGENTS.md) and [the execution contract](docs/AUTONOMOUS_EXECUTION.md). Installation instructions and a candidate package will be added only after discovery and implementation.
